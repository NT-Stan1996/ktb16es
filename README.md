# Kat#B16es
O _Kat#B16es_ é um sistema operacional de entretenimento para computadores (**não testado em hardware real**) com Intel 8086.

# Requisitos mínimos
_CPU_: Intel 8086 ou compatível

_RAM_: _640K_

Drive de disquete 3.5" (_1.44MB_)

Monitor compatível com modo texto _80x25_

# Requisitos mínimos (compilação)
Termux com `nasm` (Android | Sim, este projeto foi feito em um Android de baixa qualidade.)

Limbo x86 PC Emulator (se não quiser sofrer com QEMU no Termux)

Termux + QEMU (headless ou X11 (se quiser sofrer mesmo))

# Para o Limbo x86:
Defina `ktb16.img` como Hard Disk A e coloque seu programa no drive A.
